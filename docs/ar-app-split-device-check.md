# AR 앱 분할 — 기기 검증 체크리스트

두 앱을 같은 iPhone/iPad(LiDAR 탑재)에 설치한 뒤 확인한다. 각 항목은 화면 캡처로 근거를 남긴다.

**주의**: 이 문서를 쓰는 시점에 확인된 것은 **CI에서 두 앱 모두 컴파일에 성공했다**는 것뿐이다
(HEAD `77e7cde` 기준 <https://github.com/youngbrain85/lh-rebar-ar/actions/runs/31010767383>).
아래 항목은 전부 기기에서 아직 실행해 본 적이 없다 — 이 저장소가 있는 PC에는 시뮬레이터도
실기기도 ARKit을 쓸 수 없으므로(시뮬레이터는 ARKit 미지원, 이 PC는 Windows) 사람이
iPhone/iPad에서 직접 확인해야 한다.

| # | 확인 | 기대 |
|---|---|---|
| 1 | 홈 화면 | 두 앱이 **각각 별도 아이콘**으로 존재 (`철근 AR 연구`, `LH 철근검측`) |
| 2 | 두 앱 동시 실행 | 번들 ID 충돌 없이 각각 실행됨 |
| 3 | LH 앱 툴바 | 공유(shareplay) 버튼이 **없음**, 자(ruler) 버튼이 **있음** |
| 4 | 연구과제 앱 툴바 | 자 버튼이 **없음**, 공유 버튼이 **있음** |
| 5 | 양쪽 공통 | 현장 선택 → 모델 선택 → 배치가 동작 |
| 6 | 양쪽 공통 | 미세조정(mm/0.1°), 재고정(scope), 삭제가 동작 |
| 7 | 양쪽 공통 | 화면 캡쳐가 사진에 저장됨 |
| 8 | 양쪽 공통 | 미세조정 패드의 **투명도 슬라이더**가 모델을 실제로 반투명하게 만듦 (기존 기능) |
| 9 | 투명도 | 기본값 70%로 배치 직후부터 반투명 |
| 10 | LH 앱 | 측정이 정상 동작 (실↔실, 모델↔실) |
| 11 | 연구과제 앱 | 공유가 정상 동작 (오피스 대시보드에서 화면이 보임) |
| 12 | 기존 설치 기기(이미 테스터에게 배포된 `kr.lh.rebar-ar`)에서 build 34 업데이트 | 홈 화면 앱 이름이 **`LH Rebar AR` → `철근 AR 연구`로 바뀌어 보임** — 현재 테스터에게 가장 눈에 띄는 변화이므로 이름이 안 바뀌거나 두 앱으로 보이는 등 이상 없는지 확인 |
| 13 | 양쪽 공통, 화면 캡쳐 후 사진 확인 | 캡쳐 사진 하단 각주 첫 줄이 **앱 이름**을 정확히 표시 — 연구과제 앱은 `철근 AR 연구 · <모델명> · <일시>`, LH 앱은 `LH 철근검측 · <모델명> · <일시>` (다른 앱 이름이 찍히면 회귀) |

실패 항목이 있으면 그대로 기록한다. "대체로 동작함"으로 넘기지 않는다.
